# 🎨 UI/UX BLUEPRINT — AI CODE REVIEWER (NIST SSDF SECURE-BY-DESIGN)

Berikut blueprint komprehensif untuk halaman **AI Code Reviewer** yang mematuhi **NIST SSDF (SP 800-218)** dengan filosofi **Secure by Design** — bukan sekadar compliance checklist.

---

## 📐 INFORMASI ARSITEKTUR

```
┌──────────────────────────────────────────────────────────────────────────┐
│  ROUTE      : /ai-reviewer                                                │
│  LOKASI     : app/(dashboard)/ai-reviewer/page.tsx                        │
│  RBAC       : ✅ ADMIN  ✅ USER  ❌ VIEWER (disembunyikan)                │
│  FRAMEWORK  : NIST SSDF (PO · PS · PW · RV)                               │
│  PILAR      : Pillar 1 — AI-Powered Development + Pillar 6 — Security     │
└──────────────────────────────────────────────────────────────────────────┘
```

### Struktur Halaman (IA)
```
/ai-reviewer
 ├─ [VIEW 1] Review Dashboard      ← Landing default
 ├─ [VIEW 2] New Review Wizard     ← Pilih PR + konfigurasi
 ├─ [VIEW 3] Review In Progress    ← Live scan
 ├─ [VIEW 4] Review Results        ← Hasil utama (tab-based)
 │    ├─ Tab: Overview
 │    ├─ Tab: Security Findings    ← Core NIST SSDF
 │    ├─ Tab: Code Quality
 │    ├─ Tab: NIST SSDF Matrix     ← Compliance mapping
 │    └─ Tab: Diff Viewer
 ├─ [VIEW 5] Finding Detail        ← Drawer/side panel
 ├─ [VIEW 6] Settings              ← ADMIN only
 └─ [STATES] Empty / Loading / Error / Read-only
```

## ✅ RINGKASAN PRINSIP SECURE-BY-DESIGN

1. **Security posture first** — banner postur di atas, bukan tersembunyi.
2. **Explicit control** — user pilih SSDF practice, bukan black-box.
3. **Enforce, bukan hanya inform** — Security Gate memblokir merge.
4. **Traceability penuh** — setiap finding → CWE + SSDF + OWASP + CVSS.
5. **Audit immutable** — semua aksi tercatat, ADMIN-only, tidak bisa dimatikan.
6. **Remediation terbimbing** — AI Fix suggestion, bukan hanya deteksi.
7. **RBAC ketat** — VIEWER tidak punya akses eksekusi.
8. **Transparansi data** — retention & privacy notice eksplisit.
